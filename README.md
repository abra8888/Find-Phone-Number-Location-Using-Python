📍 Phone Locator Pro

A Python-based utility that extracts geographical information and service provider details from any international phone number. 
It leverages the phonenumbers library for parsing and the OpenCage API for high-accuracy mapping.

🚀 What it does
Carrier Lookup: Identifies the service provider (e.g., Verizon, Vodafone, Airtel).

Geographical Registration: Determines the country and region where the number was issued.

GPS Coordinates: Converts the location string into precise Latitude and Longitude.

Map Generation: Automatically creates an interactive HTML map (location.html) to visualize the result.


⚠️ Important Disclaimer
This tool uses Publicly Available Data provided by telecom registries. It provides the "Registered Location" of the SIM card, not real-time GPS tracking (which requires OS-level permissions like "Find My Device").
Always use this responsibly and within legal privacy frameworks.
